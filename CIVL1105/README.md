## Question-first study routine

1. Work down the tracker from the largest workflow groups. Check the number of distinct papers as well as rows, and give longer calculations/design questions enough time.
2. Attempt one representative question without slides. Write the governing equation or treatment diagram, assumptions and units before numbers.
3. Read only the relevant slide section to repair the missing concept. Retry independently, then attempt another session in the same group.
4. Change its status from `Not solved` to `Solved` after checking a complete independent attempt. Keep wrong assumptions and unit errors in a short personal error log.
5. During the two-week preparation period, reserve complete papers for timed mixed practice after the main workflows become familiar.
