## How to use the tables

1. Start with a **priority question** near the top: each tracker sorts workflow groups by number of question rows, largest first, and papers within each table from newest to oldest. The distinct-paper count helps judge how broadly the workflow recurs.
2. Attempt one question without notes. Write the model, assumptions, diagram or cash-flow timeline, equations, units and checks before substituting values.
3. If stuck, identify the precise missing step and consult the linked lecture. Retry the question, then solve one of the rows listed beside its `Priority status`. For example, `true: 3, 7` marks a representative question whose core steps repeat in rows 3 and 7 of that same table. Other rows show `false`; singleton groups and groups without a clear near-repeat have no priority representative.
4. Change **Not solved** to **Solved** only after completing and checking the question independently. Keep worked solutions and mistakes beside your own study notes.
5. After learning the main workflows, mix groups and attempt whole papers under their printed time and choice rules. Reserve a recent paper for this check.

Counts measure practice opportunities in the available papers; they do not predict the next exam. MCQs, structured subparts and dependent tasks are identified in each tracker. A question with several independently assessed workflows may appear in separate groups with explicit part labels. Cover low-frequency and newly added syllabus topics as well.

## Collection scope

Collected from authenticated HKU Moodle and [HKU ExamBase](https://julac-hku.primo.exlibrisgroup.com/discovery/collectionDiscovery?vid=852JULAC_HKU:HKU&inst=852JULAC_HKU&collectionId=81719117110003414) on **28 October 2026** (Asia/Singapore). Each course includes source manifests and downloaded PDFs. Papers marked as restricted and requiring lecturer contact were skipped, as requested; their metadata is recorded without question rows. Moodle folders contain the slides available on the collection date, with course outlines/schedules where supplied.

Original course and examination materials retain their authors' rights. The course overviews and question descriptions are study aids, and no official solution key is implied. Every tracker starts with all questions unsolved.
