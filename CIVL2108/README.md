# CIVL2108 - Principles of Civil Engineering Management

Start with the [past-paper workflow tracker](past-papers/README.md). It groups actual exam questions by the steps needed to answer them, with the largest groups first. Every question starts as **Not solved**.

## Course and sources

CIVL2108 is a six-credit Level 2 core course on planning, organising and controlling civil engineering projects. It connects project participants and procurement choices with financial appraisal, cost estimating and construction programming. The [current syllabus, p. 2](lecture-slides/00-course-syllabus.pdf#page=2) emphasises project success, ethical practice, time/cost management, and engineers' responsibilities before and after contract award.

Sources: [Moodle Section 1A, 2026](https://moodle.hku.hk/course/view.php?id=139619), its [2026/27 Semester 1 schedule](lecture-slides/00-course-schedule.pdf), [July 2026 syllabus](lecture-slides/00-course-syllabus.pdf), and first available lecture [Industry, life cycle, participants](lecture-slides/01-industry-life-cycle-participants.pdf).

The first lecture covers industry context (PDF pp. 2-5), construction types (pp. 5-6), project life cycle (pp. 7-11), and participants/duties (pp. 12-18). **The introductory Moodle handout begins at printed slide 5**; its opening PDF page contains the course title and an image, rather than a complete course-content list. The contents below therefore use the syllabus's explicit contents table on PDF p. 4, cross-checked against the schedule, while retaining the first lecture as the introductory reference.

The current syllabus specifies **50% continuous assessment and 50% three-hour written examination** (PDF p. 4), and includes Microsoft Project, Gantt charts and resource levelling. Historical frequency guides practice priority; it does not remove current syllabus topics.

## Question-first study loop

1. Attempt a recent representative question from a large workflow group without notes.
2. Write assumptions, diagrams, method, units and the decision criterion.
3. Read only the lecture section needed to repair a gap, then retry from a blank page.
4. Attempt another year in that group to check transfer to a different framing.
5. Change a status to `Solved` after an independent successful attempt. Reserve complete recent papers for timed practice using the instructions printed on that paper.
